# Code of conduct

The IronAFS website follows IronAFS's code of conduct: the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep discussion about the
work. Harassment and personal attacks are not tolerated, whoever they come
from.

Report a problem privately to adrian@adrianana.com. Reports are handled in
confidence. If the report concerns the maintainer, or you prefer not to
write to them, use GitHub's [report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
for anything that happened on GitHub.
