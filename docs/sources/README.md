# Sources

The research behind the statistics and dated facts on ironafs.org. The site
links each figure to its primary source; these notes record what each source
says and how it was checked.

They are working notes made with AI models (see [AI.md](../../AI.md)), kept
as written: "I" in them is the model that did the research. Among their
status words, VERIFIED means the primary source was read and the quote is exact;
SNIPPET ONLY means search-result text only, which never goes on the site
without opening the source; DROPPED means not used.
